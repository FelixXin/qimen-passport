# Offline calendar

The 2023–2100 solar-term UTC table is generated from 6tail/lunar-javascript 1.7.7, MIT licensed. The firmware supports Beijing years 2024–2099. Preserve LICENSE.lunar-javascript.txt. Generation provenance and the pinned SHA-256 remain in main/reader_qimen_terms.inc. The library is a development-only data source; JavaScript is not executed on the board. See ../../docs/SOURCES.md.
