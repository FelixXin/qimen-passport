# 0.6.1 更新内容（相对社区 0.5.0）

- Wi-Fi 列表支持上下选择，各子项可进入详情；显示热点连接数、外部网络名称、连接／重连／失败状态、IP 和信号，支持重连已保存网络。
- 默认热点密码改为 12345678；网页可分别修改热点名称和密码，保存后重启 Wi-Fi 生效，已有自定义配置保留。
- 新增“网络校时”详情，显示结果与本次开机最近成功时间，可按确定重试；外部 Wi-Fi 连接后自动尝试校时。
- 网页网络状态约每三秒刷新，连接成功取得 IP 后才保存新凭据，失败保留原配置。
- 修复连接外部 Wi-Fi 后双击确定提示操作失败、无法休眠的问题，保留休眠走时及按键唤醒。
- 重写中英文使用说明，按实际操作整理首次使用、按键、起盘、象义、网络、封面及休眠。
- 网络页面、网络校时、联网休眠及唤醒已通过原板验收。

首次安装使用完整镜像写入 0x0，可能替换程序及设置；保留资料的应用更新仅可在确认分区一致后写入 0x10000。实际待机电流、续航及长期漂移未测量。
