# 本地发布准备

1. 确认公开应用名、贡献者账号、简介、象义摘要可公开范围及代表截图。
2. 建立真实上游基线的 fork 功能分支。本抽离目录没有 Git 历史和远端，未提交或推送。只审核预期源码、测试、许可及文档；不要复制 build/、managed_components/、.agents/、私有快照和混合版旧资源。
3. 运行完整门禁，查看原生界面截图，记录完整镜像、应用、ELF 校验值；不能把混合版真机结果直接算成本版通过。
4. 获得独立刷机及写入影响授权后，验收无需词书的冷启动、完整本地日期、排盘和宫位象义、滚动翻篇返回唤醒、亮度与网络设置保存、网页手机时间回读、正确／错误配网及 BLE 窗口关闭回收。无线内存和功耗声明需另外实测。
5. 准备审核过的公开源码地址、封面及完整镜像。GitHub、官方 AI Passport 社区发布都等明确授权；验证实际发布产物，不使用后续重编译冒充。不会自动上传原始日志或 ELF／MAP。
6. 发布后可选向上游当前 plays/<用户名>/<应用名>/ 提交纯文字应用归档，执行时重新确认官方规则。独立应用源码不整体并入官方硬件测试 main。

发布操作另行记录；本清单不代表未来更新或刷机授权。独立版从 0.1.0 计版本。完整安装可能替换旧设置；阅读器旧分区需单独审核兼容的应用区更新方案。
