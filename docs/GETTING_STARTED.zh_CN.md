# 奇门随身盘 0.5.0 使用说明

## 第一次使用
开机进入奇门。无需账号、互联网或词书。先长按右侧确定键进入设置→日期与时间，上键增加、下键减少，确定依次切换年、月、日、时、分，最后确定保存；长按确定取消。当前时钟校准支持 2024—2099 年，排盘统一按北京时间 UTC+8。设置菜单第一项“当前起盘”按当前时钟重新起盘。

## 按键与排盘
九宫页上下选择宫位或上一局／下一局，确定进入详情或切局；长按上／下键切前后两小时，双击下键切下一局。长按确定打开设置或逐级返回。四柱、日期和宫位内容属于起盘快照，校时不会自动替换已有盘。

详情中，下键或确定进入符号象义，上键返回九宫。七类依次为宫的象义、天盘干、地盘干、暗干、门、星、神；上下选类，确定阅读。阅读时上下逐行滚动，读完再按下翻下一篇，篇首按上回上一篇末尾；确定回分类，长按确定回详情。第一篇页首按上返回详情，最后一篇不循环。象义用于学习，不生成自动断语。

## 省电休眠与唤醒
在已唤醒的页面双击右侧确定键，松开按键，等待设备关闭无线、屏幕和外设后进入深度休眠。黑屏期间不刷新界面、不运行排盘或提供 Wi-Fi／蓝牙服务，仅内部时钟继续计时，没有定时自动唤醒。

按任意右侧键唤醒，稍等重新初始化完成；恢复原页面、盘面和经过休眠时间后的时钟。唤醒这次按键不执行页面操作。已开启的 Wi-Fi 按保存的偏好恢复，临时蓝牙窗口需重新打开。长按左侧电源键保留硬件关机；彻底断电后无法继续走时，开机需要重新校时。

双击上键仍显示封面，无操作 60 秒也会显示低亮度封面。这是显示待机，与双击确定的黑屏深度休眠不同。原来的双击确定起当前盘已改为省电休眠，需要当前盘时从设置菜单进入。

## 指定时间起盘
设置→指定时间起盘，选择公历 1900-01-01 00:00 至 2099-12-31 23:59 内的年、月、日、时、分。上下调整，年份长按每次十年并可连续调整；确定切下一项，分钟后确定起盘，长按确定取消。历史起盘不修改当前时钟；前后局在日期边界处停止并保留原盘。历史日期统一采用固定 UTC+8，不模拟历史夏令时或真太阳时。

## 手机网页、校时与 Wi-Fi
长按确定→Wi-Fi 网络→确定开启。热点名默认 Qimen-Passport，随机密码与八位管理码显示在设备上。手机连接热点后，浏览器打开 http://192.168.4.1 ，输入管理码并连接设备。在“日期时间”页同步手机时间，或指定时间起盘。页面在前台时每 30 秒尝试同步时间，后台不保证持续同步。

在“网络”页填写外部 2.4GHz Wi-Fi 名称和密码并提交，只有对应请求显示 CONNECTED 且取得 IP 才算成功并保存。失败可检查资料重新提交，或继续通过设备热点设置。深度休眠中网页不可用；唤醒后重新连接、刷新页面。仅在可信网络使用本地网页。

## 封面与名称
设置→封面与名称，上下选择墨色太极、浅色太极、大字时钟、简洁名片或自定义图像，确定保存并预览；右侧键唤醒返回。网页“封面”页可修改最多八个支持字形的名称，留空使用应用名称；可选图、居中裁剪缩放、上传保存或恢复太极。名称、样式与图片断电保留，选择内置样式不删除自定义图片，上传中断或校验失败保留原图片。

## 蓝牙校时
设置→蓝牙校时，开启三分钟窗口。需支持自定义服务的客户端，订阅通知、发送屏幕六位 AUTH 码，再发送手机当前 UTC 秒数 TIME，具体服务与格式见源码协议文档。系统蓝牙设置不会自动发送时间或密码；iPhone Safari 无此客户端能力，可使用上述 Wi-Fi 网页。本项目不依赖微信小程序，不附带签名手机 App。

## 安装与验证范围
首次安装用社区提供的完整固件，可能替换原程序与设置，请先保存资料；应用单体不能用于首次完整安装。从 0.4.1 保留数据升级须先核对分区一致，按源码发布说明操作；0.2.0 升级还需要更新分区表。名称、网络和词书不因本次作者本地更新而擦除。

0.5.0 已在原板完成休眠、按键唤醒、时间连续和封面验收；构建、主机故障测试及界面渲染检查通过。实际待机电流、续航及长时间时钟漂移尚未测量，不承诺具体续航。社区封面为插画示意，仓库附实际渲染预览。
