# 奇门随身盘 0.6.1 使用说明

## 先记住这三个操作

- **长按确定**：九宫页打开设置；其他页面返回。
- **双击确定**：黑屏省电休眠；按任意右侧键唤醒。
- **双击上键**：九宫页显示封面；按任意右侧键返回。

下面的上、下、确定均指右侧三个按键。左侧电源键长按开关机。

## 第一次开机：校时并起盘

1. 长按确定 → **日期与时间**。
2. 上键增加、下键减少；确定依次切换年、月、日、时、分，最后确定保存。长按确定取消。
3. 返回设置，选择 **当前起盘**，确定后显示当前时刻的九宫盘。

也可通过手机网页或外部 Wi-Fi 校时，方法见下文。排盘统一使用北京时间 UTC+8；完全断电后需重新校时。

## 看盘与切局

| 在九宫页操作 | 效果 |
| --- | --- |
| 上／下 | 选择宫位或上一局、下一局按钮 |
| 确定 | 打开选中宫位的详情，或执行选中的切局按钮 |
| 长按上／长按下 | 前／后两小时的盘 |
| 双击下 | 下一局 |
| 长按确定 → 当前起盘 | 回到此刻起盘 |

顶部四柱、日期属于**本盘时刻**。校时只更新时间，不自动替换正在查看的盘。

宫位内 **○ 表示空亡，马表示驿马**。详情显示天地暗干、门星神、十二长生、月／日／时的旺相休囚死，以及入墓、击刑、门迫等状态。月份、日期、时辰的旺衰分别列出，便于比较。

## 查看七类符号象义

1. 九宫选宫 → 确定进入详情 → 按下或确定进入分类。
2. 上下选择 **宫的象义、天盘干、地盘干、暗干、门、星、神**，确定阅读。
3. 正文上下逐行滚动；读到末尾再按下，进入下一篇；篇首按上，回上一篇末尾。
4. 确定回分类；长按确定回宫位详情；详情按上回九宫。

第一篇篇首按上返回详情；最后一篇不循环。象义是学习参考，不自动生成断语。

## 指定任意时间起盘

长按确定 → **指定时间起盘**：上下调整年月日时分，确定进入下一项，最后确定起盘；长按确定取消。调整年份时，长按上／下可连续以十年为步长调整。

范围为 **1900-01-01 00:00—2099-12-31 23:59**。此操作不修改当前时钟；前后切局也不会越过范围。采用公历、固定 UTC+8，不作历史夏令时或真太阳时修正。手机网页“日期时间”也可指定时间起盘。

## 手机连接设备网页

1. 长按确定 → **Wi-Fi 网络** → 选中 **Wi-Fi 开关**，确定开启。
2. 手机连接板上显示的热点。默认名称 **Qimen-Passport**，默认密码 **12345678**；已改过的以板上显示为准。手机提示无互联网时，仍保持此连接。
3. 浏览器打开 **http://192.168.4.1**。
4. 输入板上 **网页管理码** 中的八位代码，连接设备。管理码与热点密码不同；重启或休眠唤醒后重新查看。

网页有 **封面、日期时间、网络** 三页。手机与设备连接同一路由器时，也可打开板上“浏览器地址”显示的局域网地址。

## 连接外部 Wi-Fi、查看连接情况

在手机网页 **网络** 页填写外部 **2.4GHz Wi-Fi** 名称、密码，点击连接并保存。出现 **CONNECTED／路由器已连接并显示 IP** 才算连接成功，新配置此时才保存。失败后检查名称、密码和信号再提交，原来成功保存的网络仍保留。

板上 **Wi-Fi 网络** 页上下选择、确定操作：

| 子项 | 能看到／能操作什么 |
| --- | --- |
| Wi-Fi 开关 | 确定开启或关闭网络 |
| 设备热点 | 热点名称、运行状态、连接设备数量 |
| 热点密码 | 查看当前密码及待生效提示 |
| 网页管理码 | 查看网页登录所需的八位代码 |
| 浏览器地址 | 热点地址、外部网络的局域网地址 |
| 外部 Wi-Fi | 当前／已保存名称、连接中／重连中／已连接／失败、IP、信号、失败原因；确定重连已保存网络 |
| 网络校时 | 查看校时结果及本次开机最近成功时间；确定重新校时 |

详情上下滚动；长按确定返回列表。热点、密码、管理码、地址详情也可单按确定返回。网页“网络”页约每三秒更新状态，并提供“重连已保存网络”。热点连接人数和设备连接路由器的状态是两回事。

### 改热点名称或密码

网页 **网络** 页填写新的热点名称／密码并保存；留空的项目保持不变。密码使用 8—63 位英文或数字最方便。随后在板上关闭再开启 Wi-Fi，手机用新名称、密码重新连接。设置断电保留，外部路由器配置不变。

## 三种校时方式

- **联网自动校时**：连接外部 Wi-Fi 后自动尝试网络校时。路由器已连接不代表互联网或时间服务器一定可用。
- **联网手动校时**：Wi-Fi 网络 → 网络校时 → 确定，等待结果，通常至多约 30 秒。失败可重试，不会清空已有时间。
- **同步手机时间**：手机连接设备网页 → 日期时间 → 同步手机时间。网页在前台时约每 30 秒尝试同步，切到后台不保证持续同步。

无网络时用“日期与时间”手动设置（当前时钟支持 2024—2099 年）。校时完成后，需要此刻的盘请再选 **当前起盘**。

## 换封面、名称、亮度

- **板上换样式**：设置 → 封面与名称，上下选墨色太极、浅色太极、大字时钟、简洁名片或自定义图像，确定保存并预览。按右侧键返回。
- **手机改名称**：网页 → 封面，填写最多八个设备支持的文字并保存；留空显示应用名，不支持的字会提示。
- **手机上传图片**：网页 → 封面，选图、裁剪缩放、检查预览后保存。也可恢复太极；恢复不清除名称，选内置样式不删除已上传图片。
- **调亮度**：设置 → 屏幕亮度，上下调整四档，确定返回。

名称、样式和图片断电保留；上传失败保留原图片。

## 封面待机、休眠、关机的区别

| 状态 | 怎么进入 | 时间与网络 | 怎么回来 |
| --- | --- | --- | --- |
| 低亮度封面 | 九宫双击上键，或无操作 60 秒 | 继续显示时间，程序仍运行 | 任意右侧键 |
| 黑屏省电休眠 | 清醒页面双击确定，松开按键后等待黑屏 | 内部继续走时，停止排盘和无线服务 | 任意右侧键，稍等恢复原页面和盘面 |
| 硬件关机 | 长按左侧电源键 | 断电后不走时 | 再开机并校时 |

想省电请用**双击确定**，只看封面不会进入深度休眠。唤醒的第一次按键只负责唤醒；Wi-Fi 按原开关状态恢复，网页必要时重新连接。

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 显示需要校时 | 手动设完整日期，或用手机／网络校时，再选当前起盘 |
| 连上路由器但校时失败 | 网络校时页重试，或用网页同步手机时间 |
| 手机连不上热点 | 核对板上名称和密码，确认 Wi-Fi 已开启；改密后重连 |
| 网页打不开／管理码不对 | 唤醒设备、保持热点连接，重新查看地址和管理码 |
| 校时后四柱没有变 | 本盘保留原时刻，设置 → 当前起盘即可 |

## 蓝牙与安装补充

蓝牙校时需使用兼容本项目协议的客户端：设置 → 蓝牙校时，开启三分钟窗口，按屏幕认证后发送时间。手机系统蓝牙配对本身不会自动校时；普通使用优先用网页。项目不依赖微信小程序，协议见仓库文档。

首次安装使用社区完整固件，可能替换原程序及设置，请先备份。已有设备保留资料升级需先核对分区，见仓库发布说明。0.6.1 的网络页面、校时、联网休眠及唤醒已通过原板验收；实际待机电流、续航和长期走时误差尚未测量。
