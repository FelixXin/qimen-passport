# 奇门随身盘 0.4.1 使用说明

0.4.1 已在 AI Passport 原板安装并验收封面选择、确定预览、唤醒和英文移除；写入校验、USB 版本读取、校时通过。1900／2099 年起盘与当前时钟隔离已在 0.4.0 检查。无线连接、全范围历史盘一致性、首次完整安装和功耗仍不属于此次验收。封面为插画示意，另附实际程序渲染预览。

## 第一次使用
开机默认进入奇门。无需账号、互联网或词书。排盘使用北京时间，支持 1900—2099 年（当前时钟校准限 2024—2099 年）。先长按右侧确定键打开设置，进入本地校时：上键增加、下键减少当前字段，确定依次切换年、月、日、时、分，最后确定保存；长按确定取消。保存后可起当前盘。断电后需要重新校时。

## 排盘与查看
九宫页上下选择宫位或“上一局／下一局”，确定进入详情或切局。长按上／下键可切前后两小时；双击下键切下一局，双击确定起当前盘。盘上四柱和日期对应本盘时刻，不会随校时偷偷改变已有盘面。

宫位详情显示天地暗干、门星神、十二长生、月／日／时旺衰，以及入墓、击刑、门迫、空亡、马星。下键或确定进入符号象义；上键或长按确定返回九宫。

象义页顶部七类为：宫的象义、天盘干、地盘干、暗干、门、星、神。上下选类，确定阅读。正文上下每次滚动一行；读到末尾后再按下进入下一篇，篇首按上回上一篇末尾。确定回分类选择，长按确定回宫位详情。第一篇页首按上返回详情，最后一篇不循环。象义只用于符号学习，不自动生成断语。

## 用手机网页校时或配置网络
长按确定→Wi-Fi 网络→确定开启热点。热点名 Qimen-Passport，随机密码与八位管理码显示在设备屏幕上。手机连接该热点后打开 http://192.168.4.1 ，输入管理码，点击同步手机时间；如需更新盘面，再起当前盘。网页在前台时每 30 秒尝试同步时间，后台不保证持续同步。

在同一网页填写外部 2.4GHz Wi-Fi 名称和密码。只有请求编号对应的 CONNECTED 成功状态、且设备取得对应 IP 后，才确认连接并保存；仅收到请求不代表成功。失败后检查网络资料并重新提交，或继续使用热点页面。请仅在可信网络使用本地网页。

## 蓝牙校时
长按确定→蓝牙校时，开启三分钟连接窗口。需要支持自定义蓝牙服务的客户端：订阅通知、发送屏幕六位 AUTH 码，再发送手机当前 UTC 秒数 TIME。具体服务与指令见公开仓库的协议说明。手机系统蓝牙设置不会自动发送时间或 Wi-Fi 密码；iPhone Safari 也不提供此功能，可优先使用上述 Wi-Fi 网页。本项目不依赖微信小程序，也不附带已签名的手机 App。

## 待机与安装
双击上键进入低亮度封面，无操作 60 秒也会进入封面待机。第一次右侧按键只唤醒，之后才执行操作。

首次安装使用本次完整合并镜像，从 0x0 写入，可能替换已有程序和设置。应用单体文件不能当作完整镜像刷入。已有混合版设备保留数据的更新需要单独审核，本次发布不会替你操作设备。源码、许可和校验值见 GitHub 仓库及预览版 Release。

## 封面和名称

设置中选择“封面与名称”，确定可预览默认太极封面。手机连接 Wi-Fi 后，在网页“封面”页保存名称、选图裁剪和缩放、上传保存或恢复太极图像。名称与图像断电保留；名称最多八个字，留空使用应用名称。从 0.2.0 升级须更新分区表并保留恢复备份；0.3.x／0.4.x 分区核对一致后可只更新应用。

## 历史起盘与样式

长按确定→指定时间起盘，选择北京时间的年、月、日、时、分；范围为 1900-01-01 00:00 至 2099-12-31 23:59。年份长按每次十年，可持续调整；确定切下一项，最后确定起盘。长按确定取消。历史起盘不会修改当前时钟；双击确定仍可回到当前时刻的盘。前后局在范围边界处停止，保留原盘。

设置→封面与名称，上下选择五个样式，确定保存并预览。自定义图片须先在网页上传，选择内置样式不会删除它。网页支持“应用样式”和“跳转到此时刻”，后者不会先发送校时。
